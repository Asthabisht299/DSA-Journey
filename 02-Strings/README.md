
# Strings

Strings are a fundamental topic in Data Structures and Algorithms (DSA). A string is a sequence of characters used to represent text. In Java, strings are objects of the String class and are immutable.

This folder contains Java solutions to string-based coding problems from LeetCode, focusing on character manipulation, pattern recognition, and efficient problem-solving techniques.

## 📌 Topics Covered

- String Traversal
- String Manipulation
- Character Frequency Counting
- Hashing with Strings
- Palindrome Problems
- Anagram Problems
- Two Pointers on Strings
- Sliding Window on Strings
- Substrings and Subsequences
- String Matching and Pattern Searching
- Longest Common Prefix
- String Compression
- StringBuilder-Based Problems

## 🎯 Learning Focus

Developing problem-solving skills through string-based LeetCode challenges, understanding different approaches, and analysing time and space complexity.
