
# Contains Duplicate

- **LeetCode Number:** 217
- **Difficulty:** Easy
- **Topics:** Array, Hash Table

## Problem Description

Given an integer array, return true if any value appears at least twice in the array. Return false if every element is distinct.

## Example 1

**Input:**
nums = [1, 2, 3, 1]

**Output:**
true

**Explanation:**
The number 1 appears more than once.

## Example 2

**Input:**
nums = [1, 2, 3, 4]

**Output:**
false

**Explanation:**
All elements are distinct.
