# Two Sum

- LeetCode Number: 1
- Difficulty: Easy
- Topic: Arrays, HashMap

## Problem
Given an array of integers and a target,
return the indices of two numbers whose sum
is equal to the target.

## Example

Input:
nums = [2, 7, 11, 15]
target = 9

Output:
[0, 1]
