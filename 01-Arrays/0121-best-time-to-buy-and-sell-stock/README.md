
# Best Time to Buy and Sell Stock

- **LeetCode Number:** 121
- **Difficulty:** Easy
- **Topic:** Arrays, Greedy

## Problem Description

Find the maximum profit that can be achieved by buying and selling a stock once. The stock must be bought before it is sold.

## Example

**Input:**
prices = [7, 1, 5, 3, 6, 4]

**Output:**
5

**Explanation:**
Buy at 1 and sell at 6.
Maximum profit = 6 - 1 = 5.
