
# Arrays

## 📖 Introduction

An array is a linear data structure used to store multiple elements of the same data type in a single variable. Elements are stored in contiguous memory locations and can be accessed using their index.

In Java, array indexing starts from 0, which means the first element is stored at index 0.

Arrays have a fixed size once they are created, making them useful for storing and managing collections of data efficiently.
